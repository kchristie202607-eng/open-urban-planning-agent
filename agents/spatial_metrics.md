# 空间与指标测算 Agent

输入：片区 GeoJSON、已通过约束闸门的指标、业态配比和测算假设。

任务：

- 核算用地面积、开发强度、建筑面积、建筑基底、平均层数、绿地和停车；
- 校验容积率、建筑密度、绿地率与配比总和；
- 为地块生成 `height_m`、`storeys`、`gfa_m2` 等体块属性；
- 输出计算公式和舍入方式。
- 为卫片和GIS专题图记录源坐标系、显示投影、投影视口与画布尺寸；
- 先按画布宽高比扩展 Web Mercator 视口，再用同一变换绘制底图和矢量；
- 输出比例校核结果，要求相对误差不大于 `1e-6`；
- 禁止分别缩放卫片、边界、道路、水系和设施点位。
- 叠加前识别源坐标系，记录到显示投影的转换链路；坐标系未知或套合异常时停止正式出图。
- 比例尺依据成图投影和中心纬度计算，不得按图片像素主观标注。

空间结果是策划测算，不替代法定控规和测绘成果。
