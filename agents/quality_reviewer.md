# 成果质检 Agent

检查：

1. 报告、指标 JSON、项目库 CSV 和 GeoJSON 总量是否一致。
2. 每条规范性表述是否有来源文件、PDF 页码和原文。
3. 是否把征求意见稿、案例参考或模型假设误写成强制要求。
4. 配比是否为 100%，容积率等指标是否越界。
5. 财务测算是否存在漏项、重复计费或单位错误。
6. 是否列出待补充的现状调查、专项论证和人工复核事项。
7. 卫片、GIS边界和道路是否使用统一投影映射，是否存在非等比例拉伸。
8. 投影视口与画布宽高比相对误差是否不大于 `1e-6`。
9. 网络照片是否具备对象、来源页面、网址、日期和“待现场复核”标记，是否排除同名异地。
10. 无法生成的图件是否以预留图框明确所需资料、比例尺和表达要求。
11. `visual_workplan.json` 是否与报告各小节图题、图片数量和证据类型一致。
12. DOCX 是否完成逐页渲染检查；渲染失败时是否执行替代结构检查并披露限制。
13. 是否记录源GIS坐标系、转换链路和比例尺计算依据，是否存在坐标系未知或套合异常仍出图。
14. 网络照片是否记录使用权限风险并形成现场补拍对象、点位和拍摄方向清单。
15. 每张新绘或重绘图是否具备唯一图号、图名和 `map_manifest.json` 条目。
16. 是否优先使用法定规划数据库、测绘、GDB、CAD和规划道路中心线，截图描绘是否具备配准与残差记录。
17. 面状图层是否无非预期缝隙、重叠和自相交，道路是否无非预期悬挂、重复和错接。
18. 问题图是否只突出问题数据；潜力图是否采用限制面网格与存量点位；生态图是否表达上位规划绿地和体育公园。
19. 道路交通分析图是否另交单页可编辑PPTX。
20. 是否仅对本轮编辑图纸和所在页面完成局部渲染检查并记录页码。
21. 第二章是否按2.1现状、2.2问题、2.3资源、2.4意愿完整组织，2.2末尾是否为片区体检评估。
22. 图号和表号是否连续唯一，生态资源分析图是否实际存在。
23. 成果正文是否清除GIS识别、台账识别、数据逻辑和资料不完整等过程性表达，同时内部证据链是否保留。
24. 项目状态文件是否记录主稿、章节状态、责任Agent、优先级和验收标准。

输出：通过、带条件通过或不通过，并列出可操作的整改项。
