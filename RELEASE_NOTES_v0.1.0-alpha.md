# OUPAP v0.1.0-alpha

## Purpose

Establish a sustainable open-source foundation for an AI Urban Planning Agent Platform.

## Included

- Open-source framework architecture
- Privacy-first knowledge boundary
- Knowledge architecture documentation and provenance schema
- Runtime security model
- Community contribution workflow
- Codex application preparation materials
- Synthetic fixtures and public-safe tests

## Scope

This alpha release publishes the framework contract and evaluation foundation. Project documents, GIS, photos, reports, vector indexes, credentials, and other private knowledge remain outside the repository.

## Verification

- JSON configuration/schema validation passes locally.
- CI is configured with blocking Ruff and pytest gates.
- Final release publication remains pending branch synchronization and maintainer approval.
