# 方法论文档

> OUPAP 公共框架的**行业方法论**集合 —— 从真实规划生产实践中沉淀、经脱敏整理。

## 为什么有这一层

OUPAP 的契约是「**开放框架，私有知识**」：

- **框架是公共的** —— 智能体、工作流引擎、Schema、评估工具，任何人都可复用。
- **项目数据是私有的** —— 项目文档、GIS 数据集、规划成果、企业知识库始终留在使用者本地。

但在两者之间，还存在第三类资产：**方法论**。它是"怎么做"的知识，不含任何具体项目的位置、面积、权属或结论，却正是规划从业者最难自行摸索出来的部分。

本目录把这类方法论开放出来，让框架之外的经验也能被复用。

## 贯穿全部文档的铁律

这些方法论共享一套数据纪律，也是本项目的核心立场：

1. **数据可溯源** —— 每个结论必须能回溯到文件名、页码或图号、版本与核验状态。
2. **原文优先** —— OCR、RAG、外部知识与模型记忆**均不得替代法定原文**。
3. **不推测填充** —— 含义不明的代码、缺失的名称、无法闭合的几何，一律留空并标注待核，**严禁推测填补**。
4. **口径显式** —— 坐标系、年度、口径与参数必须写明；面积等派生指标若与已知口径不符，须标注"**须人工核验、不得直接引用**"。
5. **不假交付** —— 未安装某软件时，不得声称已生成其原生文件格式。
6. **参数有依据** —— 容差、阈值等参数必须写明取值理由，不得只给数值。

## 贡献

欢迎补充方法论。请注意：

- **仅提交不含具体项目信息的内容** —— 不得包含真实项目名称、地名、坐标、面积、权属、客户信息或未公开数据。
- 若方法论源自真实项目，请**脱敏后**提交：移除项目标识与路径，数值以"示例"标注。
- 引用外部标准或研究报告时，确认其许可允许再分发。
