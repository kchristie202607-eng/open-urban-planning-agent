# 成果图片管理与缺图占位规则

> **来源**：OUPAP 平台方法论文档 · 由私有知识库条目 `16-成果图片管理与缺图占位规则` 脱敏整理
> **适用场景**：规划成果（Word / PPT）插图的来源管控、编号归档、缺图占位与质量检查
> **脱敏说明**：已移除内部知识库编号与本地路径引用

---

## 一、强制优先级

1. **第一优先级**：使用项目资料中的图片。
2. **第二优先级**：使用项目图库中的图片。
3. **第三优先级**：项目资料和项目图库均无对应图片时，**仅保留图片占位**。

> ⛔ 不得联网寻找图片，不得自行生成图片，不得使用示意图补缺，不得使用网络图片。

## 二、统一目录与编号

所有可独立引用的图片必须归档到项目根目录 `Pictures/`，采用"三位流水号 + 空格 + 图名 + 扩展名"命名：

```text
Pictures/
001 空间结构图.jpg
002 土地利用图.jpg
003 综合交通图.jpg
004 产业布局图.jpg
```

编号从 001 连续递增且不得重复；图片替换原则上保留原编号，图名发生实质变化时同步更新图片台账。不得在正文中直接引用项目其他目录中的独立图片，应先复制或提取到 `Pictures/` 并完成登记。

## 三、允许引用的图片来源

成果引用图片时，只允许以下两种来源：

1. `Pictures/` 目录内已经编号并登记的图片。
2. 原始 PDF 中的图片，且引用时能够登记原始 PDF 文件名、页码、原图号和图名。

不得引用其他目录图片、临时文件、剪贴板图片、软件缓存图片、网络图片或未登记截图。原始 PDF 图片如需实际嵌入 Word，宜先按编号提取到 `Pictures/`，并在台账中保留 PDF 溯源关系。

## 四、图片准入要求

每张正式插图必须登记图名、图号、来源文件、版本或日期、插入章节、正文锚点和核验状态。法定规划图还应核验范围、比例尺、图例、指北针、控制线及数据时点。**来源不清、版本冲突、图文不一致的图片不得进入正式成果。**

### 阅读方向强制判定原则

图片方向必须以**"图内主体文字能够从左向右、正向阅读，文字顶部朝向页面上方"**为首要判定标准。不得仅凭图片宽高、原始 PDF 页面方向、指北针方向或地图主体形态判断旋转角度。

方向核验顺序为：主体标题与主要文字正向 → 图例和比例尺文字正向 → 地图注记正向 → 指北针及整体版式合理。

> 若主体文字倒置、侧置或顶部朝向页面下方，**即使图片已经横置或指北针朝上，仍判定为方向错误**。旋转后必须再次查看图名、图例和至少三处地图注记，确认无需转头即可连续阅读，再允许插入 Word。

## 五、缺图占位格式

```text
【插入图片】

来源：
《国土空间总体规划》

图3-2

空间结构图

图片状态：
等待人工插入
```

来源、图号或图名暂不明确时填写"**待核**"，不得推测或编造。占位应放在正文预定插入位置，并纳入图纸缺项表。

## 六、图片台账字段

图片台账至少包含：编号、文件名、图名、文件路径、来源类型、来源文件、PDF 页码、原图号、版本日期、适用章节、引用状态和核验状态。

## 七、质量检查

- 检查图片是否来自项目资料或项目图库。
- 检查独立图片是否位于 `Pictures/` 且使用连续三位编号。
- 检查成果是否只引用 `Pictures/` 图片或可追溯的原始 PDF 图片。
- 检查图号、图名、来源、正文引用和图目录是否一致。
- 检查缺图位置是否完整保留占位及"等待人工插入"状态。
- 检查是否混入联网图片、生成图片、网络图片或补缺示意图。
- 检查正式 Word 及导出 PDF 中图片是否清晰、变形、裁切或跨页。
- 检查主体文字是否从左向右正向阅读、文字顶部是否朝向页面上方；**不得只检查横竖比例**。

> 违反任一禁止要求的成果不得进入正式交付版本。

## 八、外部图片／截图资料的学习与入库（非成果插图）

适用于微信截图、公众号长图、培训课件截图等**第三方整理资料** —— 这类图片是"知识来源"而非"成果插图"，按下列规则处理：

1. **不得作为成果插图**：禁止直接插入 Word／PPT 成果，也禁止提取到 `Pictures/` 占用正式编号；`Pictures/` 只接受项目资料与项目图库图片。
2. **转录为知识条目入库**：内容以文字转录形式写入知识库专题条目，条目头部必须登记：入库日期、来源（渠道 + 日期 + 原始出处是否明确）、核验状态、关联项目。
3. **强制核验标记**：未与官方原文逐字核对的一律标 **【图片转述·待核】**，并在数字、文号、条款处逐处打【待核】；只有经官方原文核验后方可升格为【官】。
4. **注明完整性**：截图常为长文局部，须在条目内说明"可见章节/缺失章节"，缺失部分不得推测补齐。
5. **与既有台账互证**：转录内容与既有台账、知识条目冲突时（如同一文号两种名称、同一指标两个数值），必须在条目"待办"中登记冲突，**不得默认以图片内容覆盖既有记录**，也不得静默保留矛盾。
6. **禁止替代法定原文**：转录条目只能作为线索与工作底稿，成果正文引用政策时仍须回到官方原文（铁律：**OCR／RAG／外部知识／模型记忆不得替代法定原文**）。
7. **留档**：原始截图默认留存在临时目录即可（非项目资料）；若需长期留档，另行指定目录并登记来源，不并入 `Pictures/` 台账。
