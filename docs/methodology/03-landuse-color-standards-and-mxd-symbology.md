# 用地地类用色国家标准与 MXD 符号化

> **来源**：OUPAP 平台方法论文档 · 由私有知识库条目 `67-用地地类用色国家标准与MXD符号化规则` 脱敏整理
> **适用场景**：工程图件（MXD / QGS）用地地类配色校核与重建、线状要素按规范入图、符号库导出
> **脱敏说明**：已移除项目名称、地名、本地路径与内部工作流编号；标准色值源自公开国标

---

## 一、依据标准与效力判定（先判效力，再谈取色）

| 代号 | 标准 | 效力状态 | 用途 |
|---|---|---|---|
| **[A]** | 《市级国土空间总体规划制图规范（试行）》自然资源部办公厅 2021-03-29 印发 | **现行有效** | **配色基准**（附录B 用地用海配色指引表，39 条） |
| **[B]** | 《国土空间规划制图规范》GB/T XX-202X 自然资源部国土空间规划研究中心 2025-02-13 征求意见稿 | **尚未生效** | 二级类细分备选（附录A 表A.7，113 类）+ 线状要素（附录B 表B.1） |
| **[C]** | 《国土空间调查、规划、用途管制用地用海分类指南》自然资发〔2023〕234号 | 现行有效 | 用地代码与名称的唯一来源 |
| **[D]** | DB11/T 1947-2021《国土空间分区规划计算机辅助制图标准》北京市地方标准 | 有效（地方） | 交叉印证，未采其色值 |

### ⚠ 同名早期稿陷阱（实测）

网络与资料中并存**同名早期征求意见稿**，其附录配色与现行印发版**完全不同**（该版「居住用地 RGB(255,217,102)」）。

> **判定规则：以印发版为准；无法确认印发日期者不作基准；发现同名多版必须在报告中显式排除并留痕。**

## 二、标准色表结构化解析（3 个必踩坑）

从标准 PDF 抽取「代码 → 名称 → RGB」，**必须核对条数与附录边界**，第一遍自动结果不可信。

### 2.1 全角标点导致整条漏析 ★

国标 PDF 该行原文为 **`RGB(0，99,128)`**（全角逗号），只认半角的正则**整条不匹配** → 「公用设施用地」整条未被读入 → 该编码下若干二级类**全部误取了在编国标的色值**。

**修正：解析前统一执行全角→半角归一化。**

### 2.2 附录未切分，两张表被合并

制图规范的**附录B（用地用海）与附录C（规划分区）**形制相同，被自动合并 → 原报 **58 条**，实际为**用地 39 条 + 分区 21 条**。

**修正：按附录标题独立成行切分。**

### 2.3 一级类/二级类未逐级回退

- `16 留白用地` 误取 [B] `(242,242,242)`，应为 **[A] `(255,255,255)`**；
- 交通运输二级类误取灰阶 89/217 → 按 [A] **5.2.2**「交通运输、公用设施二级类可使用相同颜色叠加符号」，统一为 **[A] 交通运输用地 `(183,183,183)`**。

### 2.4 修正后效果

首轮自动取色共 **10 个类别偏差**，全部由上列缺陷引起；修正后**28 类用地 100% 命中现行 [A]**。

## 三、取色规则（定版）

```
对编码 C，按 6 位 → 4 位（二级类）→ 2 位（一级类）逐级回退；
每一级先查现行 [A]；[A] 全无命中才用 [B]，并标注"依据尚未生效"。
```

### 两级标准差异留痕（[A] 优先，逐条记录）

| 编码/类别 | [A] 2021 现行 | [B] 2025 在编 | 采用 | 理由 |
|---|---|---|---|---|
| 0801 机关团体用地 | RGB(255,0,255) | RGB(235,70,218) | [A] | 现行有效 |
| 0802 科研用地 | RGB(230,0,92) | RGB(240,0,92) | [A] | 现行有效 |
| 13 公用设施用地 | RGB(0,99,128) | RGB(0,99,127) | [A] | 现行有效 |
| 1402 防护绿地 | RGB(20,141,74) | RGB(20,141,7) | [A] | [B] 红值 7 疑为笔误 |
| 16 留白用地 | RGB(255,255,255) | RGB(242,242,242) | [A] | 现行有效 |

> ⛔ 发现标准本身疑似笔误（如某分量明显离群）时，**保留原值并记录疑点，不得静默改数**。

## 四、线状要素表达规则（线宽表等级 · 颜色表类型 · 线型表状态）

1. **线宽**：按等级分档，**同一图件线宽不宜超过 4 种**（示例：1.2 / 0.8 / 0.4 / 0.2 pt 共 4 档，满足 [B] 6.2.2）。
2. **颜色**：表类型（交通/市政/行政/绿地），用色相差异；**基础地理信息宜低纯度、低对比度、高明度**，不与人地类主色抢视觉（[B] 9.2.1）。
3. **线型**：表状态 —— 实线 = 实际存在，虚线 = 规划/在建，点划线 = 界线/中心线。
4. **线要素定版示例**：

| 图层 | 颜色 | 线宽 | 线型 |
|---|---|---|---|
| 镇域界线_线 | RGB(102,102,102) | 0.8 pt | 点划线 |
| 铁路_线 | RGB(0,0,0) | 1.2 pt | 实线 |
| 区域公路双线_线 | RGB(225,40,35) | 1.2 pt | 实线 |
| 道路红线_线 | RGB(0,0,0) | 0.8 pt | 实线 |
| 道路中心线_线 | RGB(255,0,0) | 0.4 pt | 点划线 |
| 道路用地线_线 | RGB(185,70,15) | 0.2 pt | 虚线 |
| 道路侧石线_线 | RGB(185,70,15) | 0.2 pt | 实线 |
| 主体层_线 | RGB(180,180,180) | 0.2 pt | 实线 |

5. **道路用地配色**：`1207 城镇道路用地 = RGB(163,163,163)`（[A] 2021 现行规范附录B，与 [B] 同值）。

## 五、MXD 符号化实现通道（无 pywin32 条件下）

本机 **无 pywin32 / win32com**，但 ArcGIS Desktop 的 `com/*.olb` 类型库齐全 → **用 comtypes 驱动 ArcObjects 直写 MXD 符号系统**。

### 5.1 环境

- 安装：`pip install comtypes --target _pylibs`（隔离目录，不污染环境）
- 运行时：使用 ArcGIS 自带的 Python 2.7 解释器执行

### 5.2 三条硬约束

1. ⛔ **必须先 `import arcpy`** 完成许可初始化，否则 `AoInitialize.Initialize` 返回 `E_NOTIMPL(-2147467263)`。
2. ⛔ **属性访问须区分 `comtypes.bound_named_property`**：取值 `obj.Prop()` / `obj.Prop[i]`，赋值 `obj.Prop[:] = v` / `obj.Prop[i] = v`。直接 `setattr` 会抛 "required argument missing"。须封装 `get/setp/call` 统一入口。
3. ⛔ **OLB 模块名区分大小写**：`esriGeoDatabase`、`esriDataSourcesFile`、`esriDisplay`、`esriCarto`。写成全小写会 ImportError。

### 5.3 常用操作

- 颜色工厂：`RgbColor` + `IRgbColor`；读色兼容 `IRgbColor` 与 `IColor`（`IColor.RGB` 为 `0xBBGGRR`，须按此解包）。
- 加图层：`IMap.AddLayer` **加在最上层**，需 `MoveLayer(fl, LayerCount-1)` 逐个置底；**逆序添加**才得预期压盖。
- 图层名：AddLayer 后 `FeatureLayer.Name` 可能为空 → 须回填数据集名（去扩展名）。
- 数据框坐标系：用 `setref_SpatialReference` 赋值（直接 `setattr(m,"SpatialReference",sr)` 常不生效）。
- 导出符号库：逐图层 `SaveToFile` 到 `符号库_LYR_YYYYMMDD/`。

### 5.4 ⛔ ArcMap 占用时 MXD 不可写（三通道全败实测）

| 通道 | 报错 |
|---|---|
| `os.rename` | `[Error 32]` 文件被占用 |
| comtypes `doc.Save` | `DAO.Fields 集合中找不到此项目(-2147287008)` |
| arcpy | "无法保存" |

**处置：一律先复制副本 → 改副本 → 交付副本**，并明确告知用户"**原文件未改动、关闭桌面软件后可一键覆盖**"。**不得反复重试或强行写入。**

## 六、校验与留痕

1. **回读校验**：重开工程文件逐图层读出实际符号值，输出「预期/实际/是否一致」对照 JSON。
2. **渲染校验图**：由成果数据直接渲染，**必须标注"非成果插图"**。
3. **自检清单**：每编码有取色来源 ｜ 线宽档位 ≤4 ｜ 数据框坐标系 = 要素坐标系 ｜ 无空图层 ｜ 图例标签中文一一对应 ｜ 差异表与缺口清单已入报告。
4. **交付物**：校核报告 `.md`（依据 + 效力 + 色值对照 + 差异 + 缺口 + 变更）、更新后工程文件、`.lyr` 符号库、对照 JSON、校验预览图、备份工程文件、可复跑脚本与日志。

---

## 七、铁律

- ⛔ **未安装某软件时不得声称生成了其原生文件**；MapGIS 私有格式（`.wt/.wl/.wp`）无法脱离 MapGIS 生成，只能走导入通道。
- ⛔ **不得以征求意见稿充当现行依据**；使用必须显式标注"尚未生效"。
- ⛔ **编码有值而名称为空的条目，名称不得由脚本推测补全**；按分类指南补名后须回原图与批复人工确认。
- ⛔ **原文色值不得"顺手修正"**；疑似笔误保留原值并记录。
- ⛔ **派生面积/占比与项目已知口径不符时，交付文档必须显著标注"须人工核验、不得直接引用"**。
- 图例色块、图签、比例尺等**图面附属要素不得混入成果图层**。
