# CAD → GIS 全要素转换方法论

> **来源**：OUPAP 平台方法论文档 · 由私有知识库条目 `65-CAD图纸全要素转GIS数据规则` 脱敏整理
> **适用对象**：DWG/DXF 图纸（尤其控制性详细规划用地规划图）向 GIS（GeoPackage / Shapefile）的全要素无损转换
> **核验状态**：已在示例项目实测通过（逾 13,000 实体 / 0 解析异常）
> **脱敏说明**：本文档已移除项目名称、地名、本地路径与源图文件名；文中数值来自示例项目，仅用于方法演示

---

## 一、源文件获取与保真

- 优先直接解析 **AutoCAD 完整导出的 DXF**（AC1032 = AutoCAD 2018 格式）。**不强行新起 AutoCAD 实例**，避免干扰用户已打开的图纸。
- 本机 AutoCAD 进程存在时，`[Runtime.InteropServices.Marshal]::GetActiveObject("AutoCAD.Application.XX")` 可能报 **`MK_E_UNAVAILABLE (0x800401E3)`**（跨沙箱/会话 ROT 不可见）。
  - **处置**：放弃 COM，改用既有 DXF，并在说明中标注派生关系与时间先后（DXF 派生时间须晚于 DWG 最后修改时间）。
- 目录中出现 `.dwl/.dwl2` 锁文件说明 DWG 正被打开；**打开不等于保存，DWG 的 mtime 才是版本判据**。
- 原始 DWG/DXF 一律**只读**，成果另置目录并归档源文件副本。

## 二、单位与坐标系（最易出错）

- **不得相信图档的 `$INSUNITS`**。实测某图档 `$INSUNITS=4`（毫米）但坐标量级为米；按毫米解释会得到数十公里级的非法范围。**以坐标量级 + 落位经纬度合理性反推真实单位。**
- 带号前缀的 3 度带高斯坐标：**东坐标首位 = 带号**。据此判定 EPSG 代码；无前缀版本对应另一 EPSG，**两者不可混用**。
- 同时输出 CGCS2000 地理坐标（EPSG:4490）供 Web / 在线地图使用。
- ⛔ **勿凭印象套用 EPSG 代码** —— 不同带号的 EPSG 极易记混，必须以带号与中央经线反推。

## 三、图层与几何组织

- 成果图层命名 `{原CAD图层名}_{几何类型}`，几何类型取 `面/线/点/注记/图元`；按 **CAD 原图层 × 几何类型** 拆分最忠实。
- 归类规则：
  - **面**：闭合 LWPOLYLINE / POLYLINE、HATCH、SOLID、CIRCLE（闭合环）
  - **线**：LINE、未闭合多段线、ARC、SPLINE、ELLIPSE
  - **点**：POINT、INSERT（按插入点）
  - **注记**：TEXT、MTEXT、ATTRIB/ATTDEF
  - **图元**：ACAD_PROXY_ENTITY、ACAD_TABLE、VIEWPORT 等无可用几何对象 → 写为 **GPKG 非空间属性表**（`pyogrio.write_dataframe(df, path, layer=...)` 支持，与空间图层可共存）
- **曲线离散化**：按**约 3° 圆心角**（离散步长 = 半径 × 0.05236，最小 0.02 m）。固定 `segments` 参数不可靠，须按半径自适应。
- **HATCH 解析**：`list(from_hatch(hatch))` 取 Path，再 `make_polygon_structure(paths)` —— **返回的是嵌套 list `[[exterior, *holes], ...]`，不是对象**，无 `.exterior_paths` / `.holes_of`。逐层 `node[0]` 为外环、`node[1:]` 为洞（洞本身又是同构嵌套 list，其 `[1:]` 为岛）。
- 仅当 `make_valid` 后确实得到多部件时才拆分要素，并在说明中披露"要素数 > 实体数"的差额。

## 四、图纸空间与图面附属要素

- 图签 / 图例 / 比例尺 / 指北针 / 图例色块常绘制在**图纸原点附近**，与地图实体分属两个坐标簇。
- **必须增设 `图面性质` 字段**（判据：`bounds.maxx < 1e6` → 图面附属），否则近原点碎屑会污染全库坐标范围，并使地理坐标成果产生大量 `inf`。
- **图例文字往往在图纸空间布局，不在模型空间** —— 遍历必须包含 `doc.layouts` 全部布局，只扫 `modelspace()` 会漏空。
- 地理坐标（经纬度）成果应**只保留地理实体**；图面附属要素使用图纸坐标，不在投影有效域内，无法换算。
- VIEWPORT 为图纸空间视口，坐标不具地理意义，**不得写成点要素**（否则原点出现假点）。

## 五、属性提取要点

- 逐实体保留：`句柄 / CAD类型 / 图层 / 颜色号 / 真彩色 / 线型 / 线宽 / 高程 / 源空间`，并派生 `长度_米·面积_平方米·面积_公顷·周长_米`。
- **`句柄` 是溯源关键字段** —— 任何要素都必须能凭句柄回到原图实体。
- **MTEXT 必须用 `e.plain_text()`**，否则得到 `{\fSimHei|b0|i0|c134|p49;\W0.85;070102}` 这类格式码。
- **`e.dxf.get(key, default)` 在属性不适用于该实体类型时会抛 `DXFAttributeError`，不会返回 default**。必须封装安全读取：

```python
def dxfget(e, key, default=None):
    try:
        ns = e.dxf
        if not ns.hasattr(key):
            return default
        v = ns.get(key, default)
        return default if v is None else v
    except Exception:
        return default
```

- ⚠ **批量替换陷阱**：用脚本把 `e.dxf.get(` 批量替换为 `dxfget(e, ` 时，会**连带改掉 `dxfget` 函数体内的那一行**，造成无限递归被 `except` 静默吞掉（表现为图层名全部退化为 fallback 值、成果图层数异常偏少）。**改写后必须回看函数体自身。**

## 六、由图例反查分类对照表

**工程图图例是图内权威的"代码 → 名称"来源，优于任何外部知识。**

- 版式特征：代码为纯数字 MTEXT，名称为含中文的 TEXT；代码在名称**右上方**。
- 配对规则：
  1. **限定图例区**，排除图面上并存的第二份图例副本；
  2. 候选条件 `|ΔY| ≤ 8`、`0 < ΔX ≤ 40`（"名称在代码右侧"可自动排除游离残片）；
  3. **排序键必须为 `(ΔY, ΔX)` —— 先比纵向行距，再比横向间距**。图例各列 X 对齐时相邻两行的横向间距可能完全相同，仅比距离会导致**整表错上一行**（实践首轮即踩此坑）。
- 反查文件名与图层名匹配时，代码位数写法可能不同，须做 `原样 / 去前导零 / 补足 6 位` **三路回退**。
- ⛔ 图例中查不到的代码**保持为空，严禁推测填充**。

## 七、成果组织与交付

建议目录结构（自包含、可追溯）：

```
<项目>_GIS_<日期>/
├─ <名称>_<坐标系>_<EPSG>.gpkg          # 主成果，全要素
├─ <名称>_地理坐标_EPSG4490.gpkg        # 副成果，仅地理实体
├─ 图层清册与数据字典.xlsx              # 8 表：图层清册/用地对照/实体对账/原图层属性/
│                                       #      字段字典/图面附属清单/无几何清单/异常记录
├─ 转换说明_README.md                   # 源数据、坐标系、口径、对账、限制、使用建议
├─ _数据校验预览_非成果插图.png
├─ _脚本/                               # 转换脚本、渲染脚本、转换日志、对账 JSON
└─ _源数据/                             # 原始 DWG + 导出的 DXF 存档
```

## 八、交付前 QA 清单

- [ ] **实体对账**：源 CAD 实体数 = 成果记录数（差额须逐条解释并写入说明）
- [ ] **解析异常数 = 0**（有异常须单列"解析异常记录"表）
- [ ] 无效几何 = 0、空几何 = 0、坐标系不符图层 = 0（双坐标系成果分别核对）
- [ ] 全库坐标范围落位合理；经纬度成果须与**目标行政区**的经纬度区间比对
- [ ] 投影换带后自相交的数值伪影已用 `make_valid` 修复（**只改副成果，主成果保持零改动**）
- [ ] 空图层、无几何对象、代理对象逐一列明
- [ ] 面积统计标注"CAD 图面填充口径"，**与项目记录范围不符时明确标注待核，不得直接引用**
- [ ] 校验预览图由成果数据直接渲染，明确标注"**非成果插图**"

## 九、可复用资产（模式说明）

| 脚本 | 作用 |
|---|---|
| `dxf2gis.py` | 全要素转换主脚本（图层×几何类型拆分、双坐标系、图例反查、对账与清册一次成型） |
| `render_check.py` | 由成果直接渲染校验预览图 |
